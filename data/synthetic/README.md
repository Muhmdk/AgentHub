# Synthetic retail fixtures

These small fixtures were authored for AgentHub and contain no customer, employee, or real
business data. IDs, locations, stock levels, sales history, promotions, and forecasts are
fictional. They are versioned in Git so local agent runs and tests remain reproducible.

The Phase 01 reference date is 2026-09-08. Its documented weekend forecast covers
2026-09-12 through 2026-09-13.

`corpus.json` contains the Phase 02 fictional policy and product corpus. It was authored for
AgentHub under the repository MIT license. Each ingestion derives a SHA-256 content hash and
stable chunk ID; no text was copied from a retailer or product manufacturer.
