AgentHub is available inside the cluster at:

  http://{{ include "agenthub.fullname" . }}-gateway.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Verify the release:

  kubectl --namespace {{ .Release.Namespace }} rollout status deployment/{{ include "agenthub.fullname" . }}
  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "agenthub.fullname" . }}-gateway 8000:{{ .Values.service.port }}
  curl --fail http://127.0.0.1:8000/health/ready

The migration job is a pre-install/pre-upgrade hook. Inspect it before retrying a failed release:

  kubectl --namespace {{ .Release.Namespace }} logs job/{{ include "agenthub.fullname" . }}-migrate
